# النسخة المحررة من موقع التفكّر في الموت

تتضمن هذه النسخة صفحات عربية/إنجليزية، تسعة فصول موسعة، صورًا رمزية لكل فصل، ومراجع مفتوحة للآيات والأحاديث والمصادر الطبية. فُصلت النصوص الشرعية عن النتائج التجريبية، وحُذفت الادعاءات التي لا تثبتها المصادر.

## التشغيل

الموقع ثابت بالكامل. افتح `index.html` أو ارفع المجلد إلى GitHub Pages. يبدأ تبديل اللغة من صفحة `reader.html` ويحفظ الاختيار في المتصفح.

## ملاحظة تحريرية

المحتوى ثقافي وإيماني ولا يقدم تشخيصًا طبيًا. عند وجود حالة احتضار أو أعراض طارئة يجب الرجوع إلى الفريق الطبي المختص.
