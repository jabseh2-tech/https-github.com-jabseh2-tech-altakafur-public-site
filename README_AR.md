# موقع التفكّر في الموت — محمد صبحي جبسة

هذه حزمة موقع ثابت مستقلة عن تطبيق الهاتف، وتحتوي على صفحة الكتاب وصفحة الكاتب وملفات `sitemap.xml` و`robots.txt` وبيانات JSON-LD.

## قبل الرفع

استبدل النص `https://YOUR-SITE.example` في الملفات الثلاثة التالية بالرابط النهائي للموقع:

- `index.html`
- `author.html`
- `sitemap.xml`
- `robots.txt`

يجب أن تكون الروابط كاملة وتبدأ بـ `https://`.

## رفع مجاني

يمكن رفع هذه الملفات إلى GitHub Pages أو Cloudflare Pages أو Netlify. بعد الرفع، تحقق من فتح:

- `/`
- `/author.html`
- `/sitemap.xml`
- `/robots.txt`

ثم أضف عنوان الموقع إلى Google Search Console وأرسل `sitemap.xml` واطلب فهرسة الصفحة الرئيسية وصفحة الكاتب.

لا تستخدم رابط المعاينة المؤقتة كتطبيق نهائي، ولا تضف رابط APK إلى خريطة الموقع.
